# 贪吃蛇游戏设计文档

日期：2026-10-25
状态：已确认

## 背景与目标

- **目的**：休闲娱乐/练手用的小游戏
- **功能范围**：最简版——贪吃蛇 + 分数 + 游戏结束重开，不含最高分记录、暂停、加速、难度、音效、触屏支持
- **运行环境**：仅电脑浏览器，键盘操作；纯 HTML + CSS + JS，无服务端、无构建、无外部依赖，双击 `index.html` 即玩
- **成功标准**：好玩、稳定、代码清晰

## 技术方案

三文件分离 + Canvas 渲染（已选方案 A）：

```
index.html   页面骨架：标题、分数栏、<canvas> 画布
style.css    居中布局与基础配色
game.js      全部游戏逻辑（约 150-200 行）
```

文件位于仓库根目录。

## 玩法规则

| 规则 | 定义 |
|------|------|
| 画布 | 400×400 像素，20×20 网格，每格 20px |
| 初始状态 | 蛇 3 节，居中，向右移动；分数 0 |
| 食物 | 随机生成在非蛇身的空格上，同一时间只有一个 |
| 吃食物 | 分数 +1，蛇长 +1，刷新食物 |
| 死亡条件 | 蛇头撞墙（越界）或撞自己身体 |
| 死亡后 | 画布上显示分数与"按空格重新开始"；按空格/回车重置全部状态 |
| 速度 | 固定每步 150ms，不加速 |

## 技术要点

- **游戏循环**：`setInterval` 每 150ms 执行一步。每步流程：从方向队列取方向 → 计算新头位置 → 碰撞检测 → 更新蛇身 → 重绘画布
- **渲染**：Canvas 2D API。蛇身绿色方块，蛇头用更深色区分，食物红色方块
- **输入**：方向键 + WASD 两种操控；按键写入**方向队列**，每步只消费一个方向，用于防止同一时间步内连按两键导致 180° 掉头自杀；对方向键调用 `preventDefault` 阻止页面滚动
- **非法方向**：180° 掉头判定基准是"方向队列中最后一个方向"（队列为空时为当前行进方向），与其相反的输入被忽略，避免通过队列间接掉头
- **状态管理**：游戏状态（蛇身数组、方向、食物、分数、是否结束）为模块内变量，重开即整体重置

## 错误处理

无外部输入源（无网络、无存储、无文件），唯一需要防御的是：

- 碰撞检测必须覆盖撞墙与撞自身两种情况
- 方向队列必须防止 180° 掉头
- 食物生成必须排除蛇身占用的格子

## 测试方式

不引入测试框架，使用手动测试清单验收：

1. 吃到食物后分数 +1、蛇身变长、新食物出现
2. 蛇头撞墙后游戏结束，显示分数
3. 蛇头撞自己身体后游戏结束
4. 快速连按两个方向键（如向右行进时按上再按左）不会导致瞬间自杀
5. 游戏结束后按空格，游戏完全重置并可正常继续玩
6. 方向键操作时页面不发生滚动

## 明确不做（YAGNI）

最高分记录（localStorage）、暂停功能、速度递增、难度选择、音效、穿墙模式、移动端触屏、多人模式。
